# 🚀 SMMEZY – Creative Digital Agency Landing Page

Smmezy is a modern, responsive, and animated landing page built with **React**, **Tailwind CSS**, and **Framer Motion**. It's designed for creative digital agencies, freelancers, or personal portfolios who want to showcase their services, projects, testimonials, and contact information with style and performance.

---

## 🌟 Features

- ⚡ **Fully Responsive** – Looks great on mobile, tablet, and desktop
- 🎨 **Animated Hero Section** – Engaging visuals with Framer Motion
- 💬 **Testimonials Carousel** – Smooth transitions and quote animations
- 🧠 **Client Logos Conveyor Belt** – Auto-scrolling branded showcase
- 📬 **Contact Form with EmailJS** – Sends messages directly to your email
- 💻 **Dynamic Project Routing** – React Router based portfolio system
- 🌈 **Custom Blobs and Shapes** – Unique floating background elements

---

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
- **Animations**: Framer Motion
- **Form Handling**: EmailJS
- **Routing**: React Router DOM
